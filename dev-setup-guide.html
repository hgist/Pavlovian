Task split

Task Tool

Why VS Code wins for Flutter editing

Flutter + Dart extensions (by Dart Code) are best-in-class:
  • Better autocomplete, widget snippets & hot-reload integration than the Android Studio plugin
  • Lighter and faster to open
  • Claude Code runs alongside it naturally
  • flutter run in the VS Code terminal talks directly to the emulator Android Studio already launched
↑ Android Studio's Flutter plugin exists but feels bolted-on. Most Flutter devs use VS Code day-to-day.

Path forward — step by step

1
Verify your toolchain
Run in any terminal. This reports exactly what's missing — missing SDK, unaccepted Android licenses, etc. 
flutter doctor
2
Create a new Flutter project
The existing Demo_1st_App folder is a native Kotlin project — it can't become a Flutter app. Start fresh: 
flutter create pavlovian
cd pavlovian
3
Open in VS Code
Then install the Flutter extension (id: Dart-Code.flutter) — it pulls in Dart automatically. 
code .
4
Launch emulator, then run
Start your AVD from Android Studio's Device Manager once, then back in VS Code: 
flutter run   # Flutter finds the running emulator automatically
5
Start building — screen by screen
Use the wireframes (A0–A5) as the spec. Build one screen at a time, run on emulator, then move on.
