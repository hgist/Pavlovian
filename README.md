# Pavlovian
Smartphone App. for alerting a worker to take a break

Several days a week, this App. alerts and reminds a worker to take a break (breakfast, lunch, etc.).
The user may set 3 alerts for each working day (5-6 days a week).
The user may choose the alert sound from his/her smartphone repertoire.
The user may shut off all weekly alerts, or only for a single day.
The user may name each timer for clarity.
