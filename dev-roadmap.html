Development Roadmap

Pavlovian · Flutter/Dart · 6 phases · 16 steps
Each step produces something runnable on the emulator. One Flutter concept at a time — so you can see real progress between steps instead of building everything in the dark.
1
Foundation
no business logic yet
1
Scaffold the project
Run flutter create in C:\Workspace\AI\Pavlovians. Get the default counter-demo running on the Android emulator. Confirms the toolchain works end-to-end.
Flutter concepts: project structure, main.dart, hot reload.
2
Theme & fonts
Set up the wireframe palette (#fbf7ee paper, #2a2723 ink, #e8a07a terracotta) and bundle the four fonts (Patrick Hand, Architects Daughter, Caveat, JetBrains Mono) so every later screen has the right look.
Flutter concepts: ThemeData, TextTheme, pubspec.yaml asset declaration.
3
Splash screen (A0)
Build the splash exactly as in the A0 wireframe. Pure UI, no state, no navigation yet.
Flutter concepts: StatelessWidget, Column/Row/Container, CustomPaint for the bell icon.
2
Main screen as static UI
looks like A1 but nothing reacts yet
4
Data model
Define BreakSlot (time, duration, label, enabled, running) and AppSettings (globalEnabled, perDayEnabled map, slots list) as plain Dart classes with the factory defaults (10:00 / 12:30 / 15:00, Chime sound, Sun–Thu enabled).
Flutter concepts: pure Dart classes, no Flutter imports.
5
Main screen layout (A1, hardcoded data)
Build the full A1 layout — header, global switch (visual only), day chips, day master card, three break cards, FAB. No toggles work yet.
Flutter concepts: complex widget trees, ListView, Scaffold, FloatingActionButton.
3
Interactivity
all 4 main-screen states (A1–A4) become reachable
6
Toggles wired up
The global switch, day master, and per-timer checkboxes now actually toggle. Screen visually responds (A1 ↔ A2 ↔ A3 ↔ A4 all reachable from one screen).
Flutter concepts: Riverpod providers, reactive state, ref.watch.
7
Persistence
Save toggle states with shared_preferences so they survive app restart.
Flutter concepts: async/await, key-value storage, JSON serialization.
4
Settings screen
A5 with full editing
8
Settings screen (A5 static)
Build the settings layout with all 4 sections visible. Tappable rows don't open editors yet.
Flutter concepts: navigation (Navigator.push), scrollable views.
9
Edit time / duration / label
Tapping a slot row opens an editor — 24h time picker, duration spinner (5-min steps), label text field. Changes persist via Step 7's storage.
Flutter concepts: showTimePicker, TextField, modal bottom sheets, form input.
10
Sounds + preview
Bundle chime.mp3 (default) plus 3–4 other sounds. The picker plays the selected sound immediately on tap so the user can preview.
Flutter concepts: audioplayers package, asset loading.
5
Notifications
real alerts fire on schedule
11
Foreground notifications
Add flutter_local_notifications. The "Test notification" button in Settings fires a sample notification right now while the app is open.
Flutter concepts: Android notification channels, runtime permissions.
12
Scheduled daily alarms
Schedule each enabled slot's alert at the right time on each enabled weekday. Use DateTime.now().weekday to know what day it is — no calendar permission needed.
Flutter concepts: zoned scheduling, timezone package, day-of-week math.
13
Countdown timer (▶ start / ■ clear)
Tapping ▶ start schedules an end-of-break notification for now + duration min and shows the live countdown in the card. ■ clear cancels it.
Flutter concepts: Timer.periodic for live countdown display, one-shot notifications.
6
Background & release
works when app is closed and after reboot
14
Background firing (app closed)
Switch from in-process scheduling to android_alarm_manager_plus so alarms fire even when the app is killed.
Flutter concepts: native Android AlarmManager, SCHEDULE_EXACT_ALARM permission for Android 12+.
15
Reboot survival
Add RECEIVE_BOOT_COMPLETED permission and a BootReceiver that re-schedules all alarms from persisted settings after the phone reboots.
Flutter concepts: Android-side manifest, boot listeners, restoring scheduled state.
16
Polish & release APK
App icon (hand-drawn bell), version bump, release build, sideload to your phone. Optional: short README for colleagues on installation.
Flutter concepts: flutter build apk, signing.
